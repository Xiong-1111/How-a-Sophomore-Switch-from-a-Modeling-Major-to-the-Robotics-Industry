# 代理碰撞体

本笔记说明什么是 **代理碰撞体（Proxy Collider）**，以及如何为场景添加代理碰撞体。

示例对象：

- **refrigerator**：冰箱
- **cube**：冰箱内的物体

## 什么是代理碰撞体

画面上看到的模型可以很精细（牙齿、衣服褶皱、车轮螺丝等），但物理引擎在计算「撞不撞、怎么弹」时，通常**不会**用这套精细网格——计算太慢，也容易卡顿。

因此会用一个形状更简单、更规整的碰撞体来代替真实外形做碰撞计算。这块用于替代计算的碰撞体，就叫 **代理碰撞体**。

> **代理** = 代替真实外观去做碰撞计算。

## 1. 观察碰撞是实心还是空心

在视口左上角点击眼睛图标：**Show by type → Physics → Colliders → All**。

看碰撞线框：

- 把洞、杯口、凹槽都盖成一整块 → **实体碰撞**
- 贴着网格薄壳、中间空着 → **表面 / 空心倾向**

凹形物体若被检测成实心碰撞，Play 后里面的物体常会被弹出，或无法放进内部。

## 2. 关掉主体整机凸包

1. 选中冰箱主体 Mesh（带整机碰撞的那个）。
2. 右侧 **Properties → Physics**。
3. 取消勾选 **Collision Enabled**。

这样冰箱外观仍在，但不再用整机碰撞去“封死”内腔。

## 3. 给冰箱添加代理碰撞体

1. **Create → Mesh → Cube**。
2. 将 Cube 移到冰箱底板位置，缩成薄板（略小于内腔）。
3. 选中该 Cube → **Add → Physics → Collider Preset**。
4. 关掉这个 Cube 的可见性（只保留碰撞），或把透明度调得很低。
5. 用同样方法再做：后壁、左右壁、顶板、层架。

完成后，视觉仍是精细冰箱模型，碰撞则由这些简单代理体负责。
